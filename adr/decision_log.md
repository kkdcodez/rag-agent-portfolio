# 결정 로그 (Decision Log)

## Week 3
- PDF 로더 = PyMuPDFLoader (baseline) — 빠르고 안정적, pymupdf4llm는 미검증이라 4주차 실험으로 미룸
- 생성/채점 모델 분리 (생성 gpt-4o-mini / 채점 Claude) — self-preference 편향 회피
- 임베딩 = multilingual-e5-base (CPU) 
- 의존성 = Poetry — 버전 충돌로 재현성 깨져서 버전 고정

## Week 4
- 청킹 = 언어별 차등 크기 (한국어 540/80, 영어 620/90) — 한국어가 영어보다 2.3배 밀도 높아, 한국어는 잘게·영어는 크게 잘라야 두 언어 검색이 함께 최적
- 노이즈 제거(클렌징) 미적용 — 켰더니 검색·생성 다 하락. 반복 머리말이 노이즈가 아니라 문서 제목·섹션명 등 검색 앵커였음
- PDF 로더 = PyMuPDFLoader 유지 (pymupdf4llm 기각) — 표 markdown이 자연어 임베딩엔 노이즈이고 chunk를 파편화, 표 많은 한국어에서 가장 악화
- 평가셋 = 이중언어 golden_set (한국어 20 + 영어 10) — 영어 청킹 효과를 검증하려면 영어 질문 필요, NCCN 문서 근거로 출제

## Week 5
- 한글 문서 참고문헌·색인 제거 (인덱스 19% 감량) — 로우레벨 검증에서 발견한 노이즈. 제거 후 세 지표 개선·문항 단위 부작용 0. kbcs는 챕터별 산재라 인용-밀도 필터(0.35)로 페이지 단위 제거
- Retrieval = Hybrid(BM25+Dense, RRF k=60) 채택 — CP 0.907→0.938, 4주차 고질 문항(1기·2기) dense 0.45→0.95로 해소. BM25(kiwipiepy 형태소)와 Dense의 실패 패턴이 달라 융합이 서로의 구멍을 상쇄
- BM25 토큰화 = kiwipiepy 형태소(내용어만) — 공백 분리로는 한국어 조사·어미 때문에 매칭이 되지 않음
- Re-ranking = bge-reranker-v2-m3 (top-20 → top-5) 채택 — CP는 동급이나 Faithfulness +0.025. Rerank는 검색 대상이 아니라 순서를 바꾸므로 CP가 개선을 포착하지 못함
- Multi-Query 미채택 — 집계 CP는 소폭 높으나 식이요법 문항에서 답변 생성 실패(CP 1.00인데 무응답), 생검 유형 항목 누락, 영어 질문에 한국어 변형이 생성되는 언어 누출 확인. 분산형 질문에는 유효해 선택적 적용을 향후 과제로 남김
- 평가 방식 = 자동 지표 + 답변 텍스트 정성 검증 병행 — RAGAS 수치와 실제 품질이 어긋나는 사례를 3건 확인
